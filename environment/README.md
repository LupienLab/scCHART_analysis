# Python environment

The analysis uses Python 3.11 and an mamba enviorment. The scripts depend on the scCHART package, NumPy, SciPy, pandas, AnnData, scikit-learn, statsmodels, joblib, and (for figures) matplotlib and Jupyter/IPython. epiCHAOS comparisons additionally require the Python port under `tools/epichaos_py` (install editable if needed).

The published scCHART package is [LupienLab/scCHART](https://github.com/LupienLab/scCHART) (reference version 0.1.0).
