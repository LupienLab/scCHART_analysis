# scCHART Analysis

Analysis and reproducibility repository for the RECOMB 2027 manuscript:

*Quantifying Chromatin Heterogeneity from Population-Conditioned Structural Divergence and Regulatory Programme Diversity*

This repository contains the analysis scripts, prepared datasets, numerical results, and Jupyter notebooks used to reproduce the figures and analyses presented in the manuscript.

The scCHART Python package is available at [LupienLab/scCHART](https://github.com/LupienLab/scCHART). The reference software version is **v0.1.0**.

- **`scripts/`** — Scripts used to perform the computational analyses.
- **`data/`** — Prepared input datasets required by the scripts.
- **`results/`** — Numerical results generated by the analysis scripts.
- **`notebooks/`** — Notebooks that load the results and reproduce manuscript figures.
- **`environment/`** — Software dependencies and environment specifications.

## Reproducibility

The workflow separates computation from visualization:

1. Analysis scripts use the prepared datasets to generate numerical results.
2. Results are saved in `results/`.
3. Jupyter notebooks load these outputs to reproduce the manuscript figures.

The repository uses scCHART v0.1.0. Some scCHART analyses involve stochastic sampling, including the estimation of sampling-based null distributions. Consequently, independent executions may produce slightly different numerical estimates depending on the random seed and random-number generation procedure.

### Additional Note

The epiCHAOS comparisons use an independent Python reimplementation of [epiCHAOS](https://github.com/CompEpigen/epiCHAOS) (Kelly et al., 2024), maintained under `tools/epichaos_py/`.

## Data availability

The analyses use publicly available single-cell chromatin accessibility and multiome datasets, including the Granja and Buenrostro datasets.

Prepared datasets and additional required inputs will be made available through Zenodo where redistribution is permitted. Download instructions and accession information will be added as the files are deposited.
