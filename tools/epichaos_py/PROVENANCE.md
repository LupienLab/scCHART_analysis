# epiCHAOS Python implementation

Independent Python reimplementation of epiCHAOS by Arvind Iyer.

Original method:
Kelly et al., Genome Biology (2024).
https://github.com/CompEpigen/epiCHAOS

Python source commit used for the scCHART comparisons:
ba4a41368c8c2a62f798581bd6cc53a4bb563b01

This implementation is used for benchmarking and method comparisons.
It is not part of the scCHART package and is not the official epiCHAOS R implementation.
